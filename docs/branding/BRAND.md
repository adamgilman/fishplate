# Fishplate Brand Guide

## The Mark

The Fishplate mark depicts two horizontal rail segments (left and right) with a visible gap — the joint where one rail section ends and the next begins. The blue element is the fishplate: the precision-engineered plate that bridges that gap, joining two separate rails into one continuous track.

### Metaphor

- **Rail segments** = workflow steps (grey/dark, the infrastructure)
- **The gap** = the boundary between steps
- **The fishplate** = your tool (blue, the active joining element)
- **Two rails** = the dual-track nature: defined process + actual execution

## Colors

| Token      | Hex       | Usage                         |
|------------|-----------|-------------------------------|
| Rail       | `#E2E8F0` | Rails on dark backgrounds     |
| Rail Dark  | `#0f172a` | Rails on light backgrounds    |
| Accent     | `#3B82F6` | Fishplate element (dark bg)   |
| Accent Alt | `#2563EB` | Fishplate element (light bg)  |
| Background | `#0a0e17` | Primary dark background       |

## Typography

- **Wordmark**: JetBrains Mono, weight 600, letter-spacing -0.01em
- **Fallbacks**: SF Mono, Fira Code, monospace

## Spacing

- Minimum clear space around the mark: 25% of mark height on all sides
- Gap between mark and wordmark: ~25% of mark width

## Minimum Size

- Full logo (mark + wordmark): minimum 120px wide
- Mark only: minimum 16px (use favicon.svg below 24px)

## Don'ts

- Don't rotate the mark
- Don't change the rail/plate color relationship (rails are always neutral, plates are always accent)
- Don't stretch or distort the proportions
- Don't add effects (drop shadows, gradients, outlines)
- Don't place on busy or low-contrast backgrounds without a container
